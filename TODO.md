# Things that were considered but not implemented

## Things Considered but Not Implemented

The following improvements were considered but left out to keep the solution focused on the required scope:

- Better detail page layout and styling
- Filtering and sorting of products based on tags or overall rating
- More extensive automated testing
- Additional and better UI polishing

These were intentionally not added because the application is small and time-boxed, and the existing `data/` + `ui/` separation was sufficient for the assignment.
